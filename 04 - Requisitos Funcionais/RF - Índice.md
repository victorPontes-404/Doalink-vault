# Requisitos Funcionais — Índice

Relacionado: [[00 - Início]] | [[06 - Regras de Negócio]] | [[09 - Matriz de Rastreabilidade]] | [[10 - Decisões Pendentes]]

## Visão geral
Este índice cataloga os requisitos funcionais (RF) do DoaLink. Os RFs **RF-001 a RF-009** derivam do documento base `implementacao-doalink.md`. Os demais (**RF-010+**) são **sugestões de expansão** identificadas a partir do domínio, lacunas comuns de produto e necessidades de operação/conformidade.

## Observações de cobertura
- RF-007 é o núcleo da proposta de valor da plataforma ("conectar" e "formar combinações"). Deve ser tratado como **Importante/estratégico** no roadmap, mesmo que implementado em fases.
- RNFs ausentes no documento base foram criados em [[05 - Requisitos Não Funcionais/RNF - Índice]].
