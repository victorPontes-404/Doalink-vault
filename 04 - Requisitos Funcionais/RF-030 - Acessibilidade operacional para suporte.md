# RF-030 — Suporte operacional e atendimento

**Prioridade:** Desejável (sugestão)

## Descrição
O sistema deve oferecer caminhos de suporte para participantes reportarem problemas de acesso, cadastro, propostas e dados.

## Capacidades sugeridas
- Canal de contato/suporte (formulário, e-mail institucional, help center — A definir).
- FAQ/ajuda contextual para fluxos críticos.
- Registro de ticket/chamado (se houver ferramenta interna).
- Acesso administrativo auditado para suporte assistido (ex.: reenviar confirmação), sem expor senha.
