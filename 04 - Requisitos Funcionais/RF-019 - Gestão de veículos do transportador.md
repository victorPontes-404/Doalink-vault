# RF-019 — Gestão de veículos do transportador

**Prioridade:** Desejável (sugestão)

## Descrição
O sistema deve permitir que transportadores cadastrem e gerenciem veículos/equipamentos logísticos para reutilização em disponibilidades.

## Campos sugeridos
| Campo | Observação |
|---|---|
| Apelido/identificação interna | Facilita seleção. |
| Tipo de veículo | Catálogo RF-014. |
| Capacidade e unidade | Peso, volume, pallets ou equivalente. |
| Placa/identificador | Opcional/sensível — avaliar necessidade e LGPD. |
| Restrições | Ex.: refrigerado, itens frágeis, horários. |
| Status | Ativo/inativo. |

## Regras
- Disponibilidade de transporte pode referenciar um veículo cadastrado ou informar dados ad-hoc (A definir).
- Placa, se coletada, deve ter finalidade clara e proteção adequada.
