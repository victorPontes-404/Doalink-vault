# RNF-013 — Compatibilidade de clientes

**Categoria:** Compatibilidade  
**Prioridade:** Importante (quando houver cliente web/mobile)

## Declaração
As interfaces clientes suportadas devem funcionar nos navegadores/dispositivos definidos para o público-alvo.

## Critérios (A definir conforme produto)
| Item | Requisito sugerido |
|---|---|
| Navegadores | Últimas versões estáveis de Chrome, Firefox, Edge; Safari quando relevante. |
| Mobile | Responsivo; app nativo fora do escopo atual, salvo decisão. |
| API consumers | Contrato estável e documentado para front-end e integrações autorizadas. |
