# RNF-017 — Acessibilidade detalhada (WCAG)

**Categoria:** Acessibilidade  
**Prioridade:** Importante (para cliente web)

## Declaração
A interface web deve buscar conformidade com WCAG 2.1 nível AA nos fluxos críticos (cadastro, login, criação de oferta/necessidade, resposta a proposta).

## Critérios sugeridos
- Navegação por teclado, foco visível e ordem lógica.
- Contraste adequado e texto alternativo para imagens significativas.
- Labels associados a campos, mensagens de erro acessíveis.
- Formulários compatíveis com leitores de tela.
- Evitar dependência exclusiva de cor para transmitir estado.
- Verificação: auditoria automatizada + revisão manual. Nível/meta final: **A definir**.
