# RNF-008 — Usabilidade e acessibilidade

**Categoria:** Usabilidade / Acessibilidade  
**Prioridade:** Importante

## Declaração
O sistema deve ser compreensível e utilizável por seus perfis-alvo, com feedback claro de erros/sucesso e atenção a acessibilidade.

## Critérios
| Item | Requisito |
|---|---|
| Mensagens | Erros de validação claros, associados ao campo quando possível; mensagens de sucesso confirmam ação concluída. |
| Linguagem | Português claro, consistente com glossário; evitar jargão técnico para usuário final. |
| Formulários | Indicar campos obrigatórios, formatos esperados e máscaras de apresentação. |
| Acessibilidade web (se cliente web) | Meta sugerida: WCAG 2.1 nível AA para fluxos críticos (A definir). |
| Responsividade | Interface utilizável em desktop e mobile conforme público-alvo (A definir). |
| Prevenção de erro | Confirmação para ações destrutivas/irreversíveis (cancelar, recusar, excluir). |
